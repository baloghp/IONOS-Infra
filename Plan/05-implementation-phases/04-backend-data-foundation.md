## Push secrets to OpenBao (manual)

Passwords are generated on first Ansible run and stored in `ansible/credentials/ts-ionos-backend/` (gitignored).  
**Not** under `playbooks/` — that was a path bug fixed in the roles.

On Backend (or any host with `BAO_TOKEN` and route to OpenBao):

```bash
export BAO_TOKEN='<root-or-admin-token>'
sudo -E /opt/cvforge/secrets/push-backend-postgres-to-openbao.sh
sudo -E /opt/cvforge/secrets/push-backend-valkey-to-openbao.sh
```

OpenBao paths created:

```text
prod/postgres          — superuser + connection info
prod/postgres/supabase — per-app credentials
prod/postgres/litellm
prod/postgres/unleash
prod/valkey            — host, port, password
infra/postgres         — superuser + connection info
infra/postgres/forgejo — per-app credentials
infra/postgres/woodpecker
infra/postgres/glitchtip
infra/postgres/n8n
```

## Backups

- Daily cron at 03:00 UTC per Postgres instance
- Scripts: `/opt/cvforge/postgres-prod/backup.sh`, `/opt/cvforge/postgres-infra/backup.sh`
- Retention: 14 days (gzip dumps in `backups/`)
- Restore test: `/opt/cvforge/postgres-prod/restore.sh <dump.sql.gz>`
