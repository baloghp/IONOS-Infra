Phase 5 — Backend live

ITTD platform

Public gateway and service directory for ITTD applications. Supabase, LiteLLM, and Unleash are deployed on the Backend; production apps (CVForge) follow in Phase 7.

  • Single public entry — VPS-2 terminates TLS and routes traffic to Frontend apps, Backend APIs, and Infra tools over WireGuard.
  • Per-service authentication — No shared gateway password; admin and production services enforce their own access controls.
  • Phased rollout — Backend APIs (Phase 5) are live; Infra tools (Phase 6) and CVForge apps (Phase 7) are planned.
